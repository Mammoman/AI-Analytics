# Aetherium AI Analytics Platform

A demo application pairing an Angular frontend with a Python FastAPI backend to
showcase a **simulated** real-time AI analytics dashboard: live KPIs, accuracy
trends, model usage breakdowns, source latencies, alerts, and a top-models
leaderboard. All data is generated by a random-walk simulator — there is no
real AI system behind it, and no data is persisted server-side.

## Architecture

```
┌─────────────────────────┐        WebSocket /stream        ┌───────────────────────────┐
│   Angular frontend       │ <------------------------------ │   Python FastAPI backend   │
│   (localhost:4200)       │        POST /auth/login          │   (localhost:8000)         │
│                           │ -------------------------------> │                             │
│  Landing → Login → Live   │                                  │  MetricsSnapshot simulator │
│  dashboard (6 widgets,    │                                  │  ticks every 1.5s and      │
│  drag/drop grid, theme    │                                  │  pushes JSON snapshots     │
│  toggle)                  │                                  │  over the socket.          │
└─────────────────────────┘                                  └───────────────────────────┘
```

The backend simulates a stream of `MetricsSnapshot` messages (see
[`docs/message-schema.md`](docs/message-schema.md) for the full schema, which is the
single source of truth mirrored by the frontend's TypeScript `MetricsSnapshot`
interface), and the frontend renders them live.

## Prerequisites

- Python 3.11+
- Node 18+

## Setup and run

### Option A: one command (Windows / PowerShell)

From the repo root, once both projects have their dependencies installed (see
manual setup below for first-time installs):

```powershell
./dev.ps1
```

This starts the backend (`uvicorn`, port 8000) and the frontend (`npm start`,
port 4200) as background PowerShell jobs, prints both URLs, and streams their
logs. If `backend/.venv` doesn't exist yet it prints instructions to create it
and skips starting the backend (the frontend will still start). Stop both with:

```powershell
Stop-Job aetherium-backend, aetherium-frontend; Remove-Job aetherium-backend, aetherium-frontend
```

### Option B: manual, two terminals

**Backend** — from `backend/`:

```bash
py -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe -m uvicorn app.main:app --reload --port 8000
```

The API will be available at **http://localhost:8000**.

**Frontend** — from `frontend/`:

```bash
npm install
npm start
```

The app will be available at **http://localhost:4200**.

### Bash equivalent (macOS/Linux)

From the repo root, run both in the background in one terminal:

```bash
(cd backend && .venv/bin/python -m uvicorn app.main:app --port 8000 &)
(cd frontend && npm start &)
```

## How to use it

1. Open **http://localhost:4200**.
2. On the landing page, click **Learn More** to go to the login screen.
3. Log in with **any username/password** — auth is mocked and accepts any
   non-empty credentials.
4. Explore the live dashboard: KPIs, accuracy trend, model usage, source
   latency, recent alerts, and top models, all updating in real time.
5. Click **Customize** to drag and reorder widgets, or add/remove them from
   the grid. Your layout is saved to `localStorage` and restored on your next
   visit.
6. Use the theme toggle to switch between light and dark mode.

## How the simulated data works

The backend's simulator (`backend/app`) maintains an in-memory state and, on
each WebSocket connection to `/stream`, ticks every **1.5 seconds**, nudging
each metric with a bounded random walk and pushing the resulting
`MetricsSnapshot` as JSON. No history is persisted — closing and reopening the
connection starts a fresh walk from the simulator's current state.

## Running tests

**Backend** (from `backend/`):

```bash
.venv/Scripts/python.exe -m pytest -v
```

**Frontend** (from `frontend/`):

```bash
npm test -- --watch=false --browsers=ChromeHeadless
```
